# Análise da Experiência Emocional — Presente Mágico

> **Papéis:** CEO da Apple × Diretor de Produto do Canva × Diretor de UX do Airbnb × Neuromarketing × Awwwards

---

## 1. O que faz alguém se APAIXONAR nos primeiros 10 segundos?

**HOJE:** Nada. A landing page mostra cards de template e um botão "Criar Agora". É funcional, não é mágico.

**DEVERIA SER:**
- **Tela cheia com vídeo de um presente sendo aberto** (mão real, papel rasgando, reação emocionada)
- **Som ambiente suave** ao entrar (violino/piano)
- **Frase de impacto:** "Antes de comprar mais uma caneca... que tal um presente que faz chorar?"
- **Preview AO VIVO:** Um presente real sendo exibido com animação, mostrando fotos e música
- **Zero texto explicativo** — a experiência é a explicação

---

## 2. O que faz alguém COMPRAR imediatamente?

**HOJE:** Plano Premium com funcionalidades listadas. Racional, não emocional.

**DEVERIA SER:**
- **Momento "Preview" irresistível:** Usuário cria o presente, vê o preview com a música e fotos dele → **impacto emocional próprio** → "preciso compartilhar isso"
- **Bloqueio emocional:** Ao tentar compartilhar sem pagar → "Seu presente está pronto. Para enviar, escolha o plano que cabe no seu bolso"
- **Urgência:** "Fulano acabou de criar um presente para [nome]"
- **Oferta Por Tempo Limitado:** "Preço de lançamento — R$19,90 (depois R$39,90)"
- **Prova social emocional:** Depoimentos em VÍDEO de pessoas recebendo e chorando

---

## 3. O que faz alguém INDICAR para amigos?

**HOJE:** Nada além do link do presente.

**DEVERIA SER:**
- **Ao final do presente:** "Crie um presente assim para alguém especial →" com botão "Criar Agora"
- **Ranking de emoção:** "Este presente recebeu 5 lágrimas 😢 de emoção"
- **Desafio entre amigos:** "Crie o presente mais emocionante da semana e ganhe destaque"
- **Gift Card:** "Compre um crédito para um amigo criar"
- **Coleção:** "Fulano já criou 12 presentes — veja todos"

---

## 4. O que faz alguém CHORAR ao entregar?

**HOJE:** O presente é bonito mas a entrega é só um link no WhatsApp.

**DEVERIA SER:**
- **Animação de EMBRULHO sendo aberto:** O destinatário vê um presente 3D que precisa "desembrulhar" com o dedo
- **Som de papel rasgando** ao abrir (ASMR)
- **Música tema** começa automaticamente ao abrir
- **Fotos aparecem como Polaroids caindo** do envelope
- **Mensagem aparece letra por letra** (como se estivesse sendo escrita na hora)
- **Contagem regressiva:** "Faltam 3 dias para [nome] abrir este presente" → gera antecipação

---

## 5. O que faz alguém dizer "Esse é o presente mais lindo que já vi"?

**HOJE:** É bonito, mas não inesquecível.

**PRECISA TER:**
- **Tipografia emocional:** Great Vibes (cursiva) para o nome da pessoa — manuscrito, íntimo
- **Papel de carta envelhecido** como background (textura)
- **Efeito parallax:** Fotos flutuam enquanto rola
- **Transições líquidas** entre seções (como água ou lágrimas)
- **Detalhes que surpreendem:** Ao tocar numa foto, ela vira e mostra mensagem no verso
- **Final emocional:** Ao terminar, aparece "Este presente foi criado especialmente para você por [nome]". O nome do criador aparece com caligrafia.

## Análise Tela a Tela

### Landing Page
| Elemento | Hoje | Deveria ser |
|----------|------|-------------|
| Header | Logo + links | Nada. Só o presente sendo aberto em tela cheia |
| Hero | Título + subtítulo | Vídeo vertical (9:16) de uma reação real |
| Templates | Cards com ícone | Fotos reais dos templates em uso |
| CTA | "Criar Agora" | "Começar minha magia" |
| Footer | Links | "Feito com ❤️ para quem ama" |

### Wizard de Criação
| Elemento | Hoje | Deveria ser |
|----------|------|-------------|
| Título | "Para quem é este presente?" | Foto de fundo + "Quem você quer emocionar hoje?" |
| Inputs | Campos de formulário | Perguntas que parecem carta: "Como essa pessoa se chama?" |
| Fotos | Upload tradicional | "Escolha fotos que contam a história de vocês" |
| Música | Campo de busca | "Qual música define o que vocês sentem?" |
| Mensagem | Textarea | "O que seu coração quer dizer?" + IA sugere |
| Botão final | "Gerar Presente" | "Criar Magia" ✨ |

### Página do Presente (Visualização)
| Elemento | Hoje | Deveria ser |
|----------|------|-------------|
| Entrada | Presente aparece | Animação de embrulho com papel rasgando |
| Nome | Texto normal | Caligrafia à mão com Great Vibes |
| Fotos | Grid de imagens | Polaroids caindo com som de queda |
| Música | Player simples | Interface de vitrola/vinil |
| Mensagem | Texto estático | Aparece letra por letra, como se estivesse sendo escrita |
| Contador | Número seco | "Faltam X dias" com velas/balões |
| Compartilhar | Botão | "Enviar magia para alguém" |

## Microinterações que Transformam

| Interação | Efeito |
|-----------|--------|
| Abrir presente | Rasgar papel (som + animação + confetes) |
| Rolar fotos | Parallax + zoom suave |
| Tocar coração | Ele pulsa + som de batimento |
| Compartilhar | Animação de papel dobrando em avião |
| Finalizar leitura | Página se fecha como livro |
| Carregar | Símbolo de coração pulsando (não spinner) |

## Jornada Emocional do Usuário

```
ENTRADA → Curiosidade ("O que é isso?")
  ↓
EXPLORAÇÃO → Admiração ("Nossa, que lindo")
  ↓
CRIAÇÃO → Envolvimento ("To escolhendo as fotos...")
  ↓
PREVIEW → Emoção ("Nossa, ficou PERFEITO")
  ↓
COMPARTILHAMENTO → Antecipação ("Mal posso esperar...")
  ↓
RECEPÇÃO → Surpresa → Emoção → Lágrimas → Gratidão
  ↓
INDICAÇÃO → "Preciso criar um também"
```

Cada etapa precisa de uma transição suave. O usuário nunca deve pensar "o que eu faço agora?". O fluxo deve ser tão natural quanto abrir um presente de verdade.
